## 1. 결정 사항 (✅ 2026-10-14 확정 — D1~D10 모두 제안안대로)

허브 §1의 공통 결정(브라우저 처리·DB 변경 없음·로그인 필수·라이트 테마)은 그대로 따른다. 파일은 **서버로 올라가지 않고** 브라우저에서 ZIP으로 묶어 내려받는다(허브 §2-3 — 브라우저는 사용자 PC의 파일 이름을 직접 바꿀 수 없다). 아래는 이 메뉴 고유 항목이다.

| # | 항목 | 제안 | 비고 |
| --- | --- | --- | --- |
| D1 | 이름 규칙 | **`{공통 이름}_{순번}.{원래 확장자}`** — 공통 이름·시작 번호(기본 1)·번호 자릿수(기본 3, 0 채움). 예: `상품이미지_001.pptx` | 참고 화면 그대로. 구분자 선택(`_`·`-`·공백·없음)·접두/접미 붙이기·찾아 바꾸기·원본 이름 유지 + 번호 같은 규칙은 **후속 검토**(MVP 제외) |
| D2 | 확장자·내용 | **확장자는 원본 그대로**(대소문자 포함), 파일 내용은 **바이트 그대로** ZIP에 담는다. 확장자는 **마지막 `.` 뒤만** 본다(`a.tar.gz` → `.gz`). 확장자가 없으면 번호까지만. 점으로 시작하는 파일(`.env`)은 확장자 없음으로 본다 | 이미지 재인코딩 없음 — 공용 `export.ts`의 인코딩 경로는 쓰지 않고 이름 처리만 재사용 |
| D3 | 파일 형식 | **모든 형식 허용**(이미지·문서·영상 등). 폴더 끌어다 놓기는 MVP 제외(폴더면 건너뛰고 상태 줄 + 경고 토스트로 안내 — 2026-10-14 사용자 재확인) | 참고 화면에 pptx·pdf가 섞여 있음 |

" < > |`는 `_`로 치환(공용 `sanitizeFileName`) + 입력 아래 안내. **공통 이름이 비면 번호만**(`001.pptx`). 시작 번호는 0 이상 정수, 자릿수 1~6. **파일 수가 자릿수를 넘으면**(예: 자릿수 3에 1,001번째) 그 행부터 자릿수가 늘어나므로 경고만 표시하고 저장은 허용. 같은 이름 충돌은 순번이 달라 생기지 않음(대소문자만 다른 확장자도 순번이 달라 무관) | Windows 예약 이름(`CON` 등)·끝 공백/점은 공통 이름 정리 시 함께 처리 |
| D8 | ZIP 저장 | `jszip`(설치됨, 이미지 분할에서 사용) — **무압축(STORE)**으로 묶는다(이미 압축된 형식이 대부분이라 빠르고 메모리 적음). ZIP 파일명 `{공통 이름}.zip`(비면 `renamed_files.zip`). 진행률 표시(`generateAsync`의 `onUpdate`), 생성 중에는 목록 편집·저장 버튼 잠금 | **한글 파일명**: jszip은 UTF-8 플래그로 기록한다 → Windows 탐색기 기본 압축 풀기·macOS 압축 유틸리티에서 한글이 깨지지 않는지 **P3에서 반드시 확인**(구버전 반디집·알집 설정에 따라 깨질 수 있음 — 안내 여부 판단) |
| D9 | 폴더에 직접 저장 | **MVP 제외**. File System Access API(`showDirectoryPicker`)는 Chrome·Edge만 지원하고, 원본 파일을 바꾸는 게 아니라 고른 폴더에 **새 이름으로 복사본을 쓰는** 방식이다 → 후속 검토(지원 브라우저에서만 버튼 노출) | 허브 §2-3 |
| D10 | 테스트 | 순수 로직(이름 생성·확장자 분리·정렬·상한·캡처 이름·이름 정리)은 vitest. 로컬 E2E는 헤드리스 Chrome에서 파일 추가(`uploadFile`)·끌어다 놓기·붙여넣기(합성 `ClipboardEvent`) → ZIP 다운로드(CDP `Browser.setDownloadBehavior`)를 **jszip으로 다시 열어 이름·순서·내용 바이트 일치** 검증 | 허브 §5 방식(puppeteer-core는 세션 스크래치에만 설치). 의존성 추가 없음 |

## 2. 기능 명세 (참고 화면 기준 → 이전 메뉴 레이아웃으로 재배치)

**참고 화면의 구성**: 상단 붙여넣기·파일 추가·전체 삭제·「8개 · 56.4 MB」 → 공통 이름·시작 번호·번호 자릿수 → 「최대 2,000개 · 합계 300MB 이하」·「원본 이름순 정렬」 → 표(원본 이름 / 변경 후 이름 / 순서·삭제) → 「새 이름으로 ZIP 저장」 + 상태 문구 → 「이렇게 사용하세요」 3단계.

**레이아웃(이전 메뉴와 같은 틀)**: 페이지 헤더(`page-header-title` 「파일명 일괄 변경」) + **좌측 작업 영역 + 우측 410px 패널**(xl 이상). xl 미만은 「이름 규칙」 Sheet(모바일 하단 / 태블릿 오른쪽) — QR 코드 생성 `QrCodePage` 패턴. `MainLayout` 수정 없음.

**작업 영역(좌)**
- 도구 줄: 「붙여넣기」·「파일 추가」·「전체 삭제」 버튼 + 개수·합계 용량(「8개 · 56.4 MB」) + 오른쪽 「원본 이름순 정렬」
- 파일이 없을 때: 업로드 영역(클릭·끌어다 놓기·Ctrl/⌘+V 안내 + 「최대 2,000개 · 합계 300MB 이하」) + **「이렇게 사용하세요」 3단계** 안내
- 파일이 있을 때: **표** — 원본 이름 / 변경 후 이름(강조색) / 순서·삭제(↑ ↓ 삭제). 표 영역만 스크롤(헤더 고정), 긴 이름은 말줄임 + 툴팁(공용 Tooltip). 작업 영역 전체가 끌어다 놓기 대상(놓으면 목록 뒤에 추가, 끄는 중 테두리 강조)
- 상태 문구(`aria-live`): 「목록에 추가했습니다. 확장자와 파일 내용은 그대로 유지됩니다.」, 상한 초과 시 「N개는 상한(2,000개·300MB)을 넘어 추가하지 않았습니다」 등

**우측 패널**
1. **이름 규칙** — 공통 이름(텍스트), 시작 번호(숫자), 번호 자릿수(숫자) + 예시 한 줄(「상품이미지_001.pptx ~ 상품이미지_008.pdf」) + 검증 안내(D7)
2. **저장** — 「새 이름으로 ZIP 저장」(파일이 없으면 비활성) + ZIP 파일명 미리보기 + 진행률
3. 안내 — 파일은 서버로 올라가지 않음, 확장자·내용 유지, 브라우저는 원본 파일 이름을 직접 바꿀 수 없어 ZIP으로 내려받는다는 설명(짧게)

**1280px 미만 (P5 확정)**: 「이름 규칙」 Sheet를 없애고 **이름 규칙(세 칸)·바뀔 이름을 본문 위 카드**로, 저장을 **헤더 「새 이름으로 ZIP 저장」 버튼**(아이콘 없음, ZIP 파일명은 마우스 오버 툴팁)으로 옮겼다. 규칙이 세 칸뿐이라 Sheet에 숨기면 목록을 보며 바꿀 수 없고 Sheet 내용이 본문과 겹치기 때문이다. **768px 미만**은 표 대신 「원본 이름 → 변경 후 이름」 2줄 카드형 목록.

### P0 — 라우트 골격 (✅ 2026-10-14, 사용자 확인 완료)

### P3 — ZIP 저장 (✅ 2026-10-14, 사용자 확인 완료)

  - `createRenameZip`: 새 이름으로 파일을 담는다(내용 바이트 그대로). 원본 `File`(Blob)을 그대로 넘겨 jszip이 생성할 때 읽는다
  - `ZIP_GENERATE_OPTIONS`: **무압축(STORE)** + `streamFiles`
  - **한글 파일명**: jszip이 ASCII가 아닌 이름에 UTF-8 플래그(범용 비트 0x0800)와 Unicode Path 확장 필드를 함께 기록한다(소스 `ZipFileWorker.js`에서 확인)

    - jszip은 DOS 날짜를 **UTC**로 쓰는데, 압축 프로그램은 ZIP 날짜를 **현지 시각**으로 읽는다
    - 그대로 두면 한국(UTC+9)에서 풀었을 때 9시간 앞당겨진다 → `toZipLocalDate`로 UTC 필드가 현지 시각과 같아지도록 옮겨 기록한다
  - `createProgressReporter`: 진행률을 0~100 정수로 바꾸고, 같은 값은 건너뛰어 화면 갱신을 줄인다
  - `findUnreadableFile`: 생성에 실패하면 각 파일의 첫 1바이트를 읽어 **읽을 수 없는 원본 파일**을 찾는다(목록에 넣은 뒤 원본을 옮기거나 지운 경우)

### 알려진 위험·주의

- **메모리**: `File`은 디스크를 참조하므로 목록에 담는 것만으로는 메모리를 쓰지 않지만, ZIP 생성 시 결과 Blob(최대 약 300MB)이 메모리에 올라간다. 모바일·저사양 PC에서 실패할 수 있어 `generateAsync` 실패를 잡아 「파일 수나 용량을 줄여 다시 시도」 안내를 띄운다.
- **원본 파일이 이동·삭제된 경우**: 목록에 넣은 뒤 원본을 지우면 ZIP 생성 시 읽기 오류(`NotFoundError`)가 난다 → 해당 파일 이름을 알려 주는 안내.
- **ZIP 안 한글 이름**: §D8 비고. 압축 프로그램 설정에 따라 깨질 수 있다.
- **붙여넣기 권한**: `navigator.clipboard.read()`는 HTTPS·사용자 제스처·권한 프롬프트가 필요하다. 개발망·운영망은 HTTPS. paste 이벤트(`Ctrl+V`)는 권한 없이 동작하므로 이것을 기본 경로로 둔다.
- **입력창 포커스 중 붙여넣기**: 공통 이름 입력에 포커스가 있을 때 `Ctrl+V`는 텍스트 붙여넣기여야 한다 → 클립보드에 파일이 없으면 기본 동작을 막지 않는다.
