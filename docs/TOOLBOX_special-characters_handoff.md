## 2. 기능 명세 (제안)

**작업 영역(좌)**: 검색창, 카테고리 탭, 본문 격자. 격자 칸 클릭 → **즉시 복사 + 토스트 + 조합 입력창에 이어 붙임**(D5 B안).

**우측 패널**: ① 조합 입력창(직접 타이핑 가능) + 「전체 복사」·「지우기」 ② 최근 사용 ③ 즐겨찾기. xl 미만은 Sheet(위치는 D5 비고 참고).

**본문 격자 상세**: 문자(또는 이모지) 칸. 호버/포커스 시 이름(툴팁)과 유니코드 코드포인트 표시. 키보드(Tab·Enter/Space)로 조작 가능. 텍스트 이모티콘은 칸 폭이 가변이라 목록형(카드) 배치.

**카테고리(안, 구현 시 조정)**
- 특수 문자: 화살표 · 수학/단위 · 통화 · 도형(●■▲) · 별·하트 · 체크·표시 · 괄호·따옴표·문장부호 · 숫자·원문자(①㉠) · 그리스·로마 · 한글 자모/호환 · 선(박스 드로잉)
- 이모지: 표정 · 사람·제스처 · 동물·자연 · 음식 · 활동 · 여행·장소 · 사물 · 기호 · 국기 (D6)
- 텍스트 이모티콘: 기쁨 · 슬픔 · 놀람 · 화남 · 인사·응원 · 동물 · 기타
- 보조: 최근 사용 · 즐겨찾기

### P4 — 조합 입력창·최근 사용·즐겨찾기 (✅ 2026-10-12, 사용자 확인 완료)

**동작 (우측 패널 「조합·최근 사용」)**
- **조합 입력창(D5 B안)**: 격자·검색 결과·최근·즐겨찾기 어느 칸이든 클릭하면 **클립보드에 복사하면서 입력창에도 이어 붙는다**(모드 전환 없음). 입력창은 직접 타이핑·수정 가능, 글자 수(`N자`, grapheme 기준 — 이모지·국기 1글자) 표시, 최대 1,000자.
  - **커서 위치에 삽입**하고 선택 범위가 있으면 그 범위를 대체한다. 격자를 클릭해 입력창 포커스가 빠져도 마지막 커서 위치를 기억해 거기에 이어 붙이고, 삽입 뒤 커서는 삽입 문자 뒤로 이동한다(연속 클릭 시 계속 이어짐).
  - **텍스트 이모티콘은 앞에 글자가 있고 공백/개행으로 끝나지 않으면 공백 한 칸을 먼저 넣는다**(`안녕 ^_^`). 특수 문자·이모지는 그대로 붙인다.
  - 「전체 복사」(토스트 `N자를 복사했습니다`)·「지우기」(비우고 입력창에 포커스). 비어 있으면 두 버튼 비활성. 1,000자를 넘기면 이어 붙이지 않고 토스트로 안내(복사·최근 기록은 정상).
  - 복사가 막힌 환경(권한 거부 등)에서도 입력창에는 이어 붙는다(입력창에서 직접 복사할 수 있도록). 이때 오류 토스트를 띄우고 **최근 사용에는 기록하지 않는다**(복사에 성공했을 때만 기록).
  - 입력창 내용은 **저장하지 않는다**(새로고침 시 비어 있음).
- **최근 사용**: 복사 성공한 문자를 최대 30개, 최근 것이 맨 앞. 이미 있으면 끌어올리고 중복 없음. 「모두 지우기」(즐겨찾기는 유지). 항목은 `(n/30)` 표시.
- **즐겨찾기**: **방금 복사한 문자**를 추가·해제하는 버튼이 두 곳에 있고 같은 상태를 공유한다(A+C 조합, 사용자 결정 2026-10-12). 추가한 순서대로 뒤에 붙고 최대 60개(상한이면 오류 토스트). 즐겨찾기·최근 칸을 클릭하면 복사 + 이어 붙이기 + 마지막 복사 갱신(두 버튼 상태도 따라감). 격자 칸마다 별을 달지 않은 것은 화면을 어지럽히지 않기 위함(칸 수가 수백 개).
  - **A. 우측 패널 「즐겨찾기」 제목 옆 버튼**(`data-testid=fav-toggle-panel`): 목록과 같은 곳이라 찾기 쉽다. 복사 전에는 비활성 「방금 복사한 문자 추가」, 복사 후 「「→」추가」/「「→」해제」(★ 채움, `aria-pressed`). 긴 이모티콘도 `truncate`로 패널 밖으로 넘치지 않음. 1280px 미만에서는 Sheet 안 패널에 같은 버튼이 있다.
  - **C. 화면 아래 고정 안내줄**(`data-testid=copied-bar`, sticky): 「복사됨: → 오른쪽 화살표 (U+2192) [☆ 즐겨찾기]」가 칸이 많은 카테고리를 스크롤해도 **항상 화면 아래에 보인다**(이전에는 격자 맨 아래라 스크롤해야 보였음). `bg-neutral-50/95`+블러+위 경계선. 맨 아래까지 스크롤하면 패널 아래 제자리에 놓여 마지막 칸을 가리지 않는다.
  - 구현 메모: ① sticky 기준선은 스크롤 영역의 아래 패딩(`pb-8`)만큼 올라가 바 밑에 32px 틈이 생기므로 `-bottom-8`로 상쇄했다(E2E가 868 vs 900으로 잡음). ② 고정 바에 키보드 포커스 칸이 가려지지 않도록 스크롤 영역에 `scroll-pb-24`를 줬다(Tab 120칸 이동 검증). ③ 패널 버튼 문구는 「「→」」와 「추가」 사이를 공백이 아니라 여백 스타일로 띄워 `textContent`는 붙어 있다(접근성 이름은 `aria-label`).
- **저장**: `localStorage` 키 `toolbox:special-characters:v1`, 형식 `{ v: 1, recent: [{char,name,emoji?,wide?}], favorites: […] }`. 문자 목록뿐이라 개인 정보가 아니어서 저장한다(QR 코드와 다름). 저장소가 차단·용량 초과여도 예외 없이 이번 방문 동안 메모리로 동작.
- 1280px 미만: 같은 패널이 「조합·최근 사용」 Sheet(모바일 하단 / 태블릿 오른쪽)에 들어간다. 조합 입력창·최근·즐겨찾기 상태는 페이지가 들고 있어 **Sheet를 닫았다 열어도 유지**되고, Sheet 안 입력창은 열 때 마지막 커서 위치를 복원한다.
