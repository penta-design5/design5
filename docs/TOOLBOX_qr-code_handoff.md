## 2. 기능 명세 (제안)

**작업 영역(좌)**: 생성된 QR 미리보기(화면 맞춤, 투명 배경은 체크무늬). 입력이 비어 있으면 안내 문구. 오류(용량 초과 등)는 미리보기 자리에 표시.

**우측 패널**
1. **내용** — 텍스트/URL 입력(여러 줄 허용, 글자 수·바이트 수 표시), URL 형태가 아니면 그대로 텍스트 QR. 「지우기」
2. **디자인** — 전경색·배경색(색상 선택 + 프리셋, 「배경 투명」 체크), 여백(0~10 모듈, 기본 4)
3. **오류 정정** — L 7% / M 15% / Q 25% / H 30%(기본 M). 로고 사용 시 H 고정 안내
4. **로고** — 업로드·제거, 크기 슬라이더(상한 §D4)
5. **스캔 안내** — §D7 경고(황색 배너)
6. **저장** — 형식(PNG/SVG), 크기(px 프리셋 256/512/1024/2048 + 직접 입력), 파일명, 「저장」 버튼. 파일명 기본 `qrcode`(내용이 URL이면 도메인 기반 제안은 후속)

### P1 — 입력 → 실시간 미리보기 → PNG 저장 (✅ 2026-10-12, 사용자 확인 대기)

**구조**
- `lib/toolbox/qr-code/options.ts`: `QR_DEFAULTS`(M·여백 4·검정/흰색·1024px)·`QR_BYTE_CAPACITY`·`normalizeQrText`(**앞뒤 공백·개행 제외** — 붙여넣은 URL 끝 개행으로 링크가 깨지는 것 방지)·`utf8ByteLength`

- `render.ts`: `computeLayout`(**모듈을 정수 px로 맞추고 남는 픽셀은 양쪽 여백(배경색)에 나눔** — 캔버스는 요청 크기 그대로) · `drawQr`(어두운 모듈의 가로 연속 구간을 한 번에 칠함) · `renderQrCanvas`(저장용, 모듈 <1px이면 최소 크기 안내 오류) · `previewSize`(모듈 정수 배, 목표 640px)

### P2 — 색상·투명 배경·여백·오류 정정·크기 입력·스캔 안내 (✅ 2026-10-12, 사용자 확인 대기)

**구조**
- `options.ts` 확장: `QrSettings`(ecLevel·margin·fg·bg·bgTransparent)·`DEFAULT_QR_SETTINGS`·`EC_LEVEL_OPTIONS`(L 7% / M 15% 기본 / Q 25% / H 30% + 설명)·`MARGIN_RANGE`(0~10칸)·`FG_PRESETS`·`BG_PRESETS`
- 신규 `contrast.ts`(순수): `relativeLuminance`·`contrastRatio`(WCAG)·`parseHex` + **`scanWarnings`** — 저장은 막지 않고 안내만 한다.
  - 반전(점이 배경보다 밝음) / 낮은 대비(3:1 미만, 반전과는 하나만 안내) / 투명 배경(바탕색에 따라 스캔 불가) / 여백 2칸 미만 / 저장 크기에서 점 1칸이 3px 미만
- `render.ts`: `QrPaint.bg`가 `null`이면 **투명 배경**(`clearRect`만, 배경 사각형 없음 — P3 SVG도 동일하게 배경 사각형 생략) · `qrSizeError`(정수·공용 `validateOutputSize` 상한·모듈 수+여백보다 작으면 「최소 Npx」)
- UI: `QrColorField`(프리셋 + `<input type="color">`, 투명이면 배경 색 비활성) · `QrSidePanel`(내용 / **디자인**: 점·배경 색·배경 투명·여백 슬라이더 / **오류 정정** 선택 / **스캔 안내**(황색 목록, 경고가 있을 때만) / 저장: **크기 입력(px)**·파일명·버튼) · `QrPreview`(투명 배경이면 캔버스 뒤에 체크무늬 — 캔버스 픽셀은 그대로 투명)
- 동작 규칙
  - 오류 정정을 바꾸면 행렬을 다시 만든다. **같은 내용이 선택한 수준의 용량을 넘으면** 미리보기가 사라지고 용량 안내가 나온다(수준을 낮추면 복구). 내용 입력창 아래에 현재 수준의 용량을 표시한다.

### P3 — SVG 저장·형식 선택·크기 프리셋 (✅ 2026-10-12, 사용자 확인 대기)

- 신규 `lib/toolbox/qr-code/svg.ts`: `renderQrSvg(matrix, size, margin, paint)`

- UI: 저장 섹션에 **형식 선택**(「PNG · 이미지 (투명 배경 가능)」/「SVG · 벡터 (인쇄·디자인용)」+ 용도 안내), **크기 프리셋 버튼 4개**(선택 표시는 입력값 기준, 직접 입력하면 해제), 버튼 「PNG로 저장」/「SVG로 저장」, 파일명 미리보기 확장자 연동
- 동작 규칙
  - 형식을 바꾸면 크기 입력값은 유지하고 형식 규칙으로 다시 검증한다(예: SVG에서 5000px → PNG로 돌아오면 픽셀 상한 안내·저장 비활성).
  - **「점 1칸 Npx」 표시와 작은 점 경고는 PNG에만** 나온다(SVG는 벡터라 크기와 무관, 인쇄 크기는 사용자가 정한다).

### P4 — 중앙 로고 (✅ 2026-10-12, 사용자 확인 대기)

**동작**
- 「로고」 섹션(디자인과 오류 정정 사이): 「로고 이미지 선택」 → 썸네일(체크무늬 배경)·파일명·크기·「변경」·삭제(X) + **로고 크기 슬라이더 10~25%(기본 20%, QR 본체 한 변 기준)**. 형식은 공용 `loadWatermarkLogo`(형식·20MB·픽셀·EXIF 검증)를 그대로 쓴다. 로고는 저장되지 않는다(새로 열면 다시 선택).
- **로고가 있으면 오류 정정을 「최고 (H)」로 고정**(드롭다운 비활성 + 안내). 사용자가 고른 수준은 보존했다가 **로고를 삭제하면 되돌린다**. 용량 표시·용량 초과 안내도 H 기준이다.
- **최소 버전 4**: 짧은 내용도 버전 4(33×33)로 올린다(`buildQrMatrix(…, minVersion)` — 자동 버전이 더 작으면 그 버전으로 다시 생성).
- 로고 아래 점은 **그리지 않는다**(검은 점 위에 로고를 얹지 않음). 지운 자리에는 **배경색이 드러나고, 투명 배경이면 투명**이다. 로고는 지운 영역 한가운데에 **비율을 유지(contain)**해 놓인다.
- PNG: 로고를 목표 크기로 단계적 축소(`resizeCanvas`)해 그린다(3000×3000 로고도 1.5초 내 저장). SVG: 로고를 **PNG data URL `<image>`로 포함**(최대 512px로 축소 — 큰 로고도 31KB), 벡터 로고는 미지원. 패널에 안내한다.
- 스캔 안내에 「로고가 점 일부를 가리므로 저장한 QR을 **사용하기 전에 스마트폰으로 꼭 스캔해 확인**하세요」(`logo` 경고)를 항상 표시한다.

**구조**
- `lib/toolbox/qr-code/logo.ts`(순수): `logoPlacement(size, percent)` → 지움 영역(정수, **QR 가운데에 대칭이 되도록 `size`와 홀짝을 맞춤**)·로고 변(실수, 모듈), `isKnocked`

**지움 면적 상한을 14% → 10%로 낮춘 근거 (실측)**
- 같은 알고리즘으로 지움 영역을 키우며 `jsQR`(H)이 언제 실패하는지 측정했다. 실패 한계(전체 대비 지움 면적): 버전 4 15.5% · 5 21% · 6 17% · 7 18% · 8 18% · 10 22%.

  - 1280px 미만에서는 **스캔 안내도 본문에 표시**하고, 헤더에 **「QR 옵션」 + 「PNG/SVG로 저장」 버튼**을 함께 둬 Sheet를 열지 않고도 저장한다(Sheet에는 디자인·로고·복원력·저장 옵션만 있고 입력창이 없다).
  - **1280px 미만에서는 우측 패널을 렌더하지 않는다**(`hidden xl:block`로 숨기기만 하면 중복 입력창·안내가 DOM에 남아 E2E에서 발견). 입력값은 상태가 공유되어 화면 폭을 바꿔도 유지된다.
  - 본문 영역은 세로 스크롤(`overflow-y-auto`)이고 좌우 여백은 모바일 16px / sm 이상 32px이다.
- **터치**: `pointer: coarse`에서 색상 프리셋 36px·직접 선택 36×48px·크기 프리셋 버튼 높이 40px·지우기 버튼 40px, **슬라이더(여백·로고 크기) 조작 영역을 8px → 40px**로 키웠다(기존 공용 `Slider`의 루트 높이가 8px뿐이라 손가락으로 맞추기 어려웠다 — 터치 진단에서 확인).
- **접근성**: 미리보기 `aria-label`에 내용 요약(앞 60자)과 버전을 넣었다(예: 「https://… 내용을 담은 QR 코드 (버전 3)」). 모든 컨트롤에 접근 가능한 이름이 있고(로고 파일 입력 포함), 미리보기·오류는 `aria-live="polite"` 영역 안이다.
- 넣지 않은 것: 단축키·도움말(필요 시 후속), 페이지 이탈 경고(입력 텍스트뿐이라 과하다고 판단), 입력·옵션 localStorage 저장(내용에 민감 정보가 있을 수 있어 저장하지 않는다 — 새로 열면 초기화).
