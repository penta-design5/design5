### 이미지 편집 공통 설계 (P1~P6에 적용)

**화면 구성(안)**
- 상단 툴바: 도구 선택(선택/자르기/펜/형광펜/직선/화살표/사각형/원/텍스트) + 실행취소/다시실행 + 내보내기
- 중앙: 캔버스(화면 맞춤·줌) — 체크무늬 배경으로 투명 영역 표시
- 우측 패널: 현재 도구의 옵션(회전 각도, 크기, 색상, 선 굵기, 워터마크 설정 등) — PDF Extractor의 우측 패널/모바일 Sheet 패턴 재사용

**레이어 모델**
- **베이스 이미지(래스터)**: 회전/반전/리사이즈/자르기는 베이스 비트맵을 새로 만드는 방식으로 적용
- **주석 레이어(벡터)**: 펜·도형·텍스트는 Konva 노드로 유지 → 선택·이동·수정·삭제 가능
- **워터마크 레이어**: 설정값 기반으로 렌더(내보내기 시 합성)
- ✅ **기하 변환 시 주석 처리 규칙 (확정 2026-09-28)**: 회전·리사이즈·자르기 적용 시, 기존 주석을 **베이스에 합쳐(flatten) 확정한 뒤** 변환한다(주석 좌표 재계산 복잡도 제거). 합쳐진 주석은 이후 개별 수정 불가(undo로는 되돌릴 수 있음). 주석이 있을 때 적용하면 "주석이 이미지에 합쳐집니다" 안내 표시

**히스토리**
- 스냅샷 방식 undo/redo(베이스 비트맵 참조 + 주석 데이터 배열), 최대 30단계(메모리 보호)
- (P1 구현) 캔버스 스냅샷이 커서 단계 상한을 이미지 크기에 맞춰 조정: 스냅샷 합계 512MB 예산 안에서 최소 5 ~ 최대 30단계 (`historyLimitFor`)
- (P1 구현) 스냅샷의 캔버스는 불변으로 취급 — 편집은 항상 새 캔버스를 만들어 교체(제자리 수정 금지). P2 이후 모든 편집 함수가 이 규칙을 따른다

**제약/예외**
- 입력 형식: PNG, JPG/JPEG, WebP, GIF(첫 프레임), BMP. HEIC 미지원 안내
- ✅ 최대 입력 크기 (확정 2026-09-28): **파일 20MB, 캔버스 약 1,670만 px(16,777,216 px = 4096×4096, Safari 한계)**. 초과 시 업로드 거부 + 안내. 리사이즈·자유 회전 결과도 같은 픽셀 상한 적용
- EXIF 회전 보정: `createImageBitmap(file, { imageOrientation: 'from-image' })`로 휴대폰 사진 방향 정상화
- 페이지 이탈 시 미저장 편집 경고(`beforeunload`)
