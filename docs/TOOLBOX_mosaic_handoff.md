# TOOLBOX「이미지 모자이크」 Handoff

> TOOLBOX 공통 규칙·로드맵·검증 방법·배포는 허브 문서 [TOOLBOX_handoff.md](TOOLBOX_handoff.md)를 본다. 이 문서는 「이미지 모자이크」 메뉴의 진행 상태 단일 원본이다.

- 메뉴: 이미지 모자이크 · slug `mosaic` · 라우트 `/toolbox/mosaic`
- 최초 작성: 2026-10-07 · 참고 속성 패널 반영: 2026-10-07
- **현재 상태: 🟡 구현 완료(P0~P6, 2026-10-07) — 사용자 확인·개발망 확인 대기** — 영역 객체(사각형·타원/원) + 패턴(거친 픽셀·부드러운 블러) + 강도 + 되돌리기 + 단축키 + 원본/비교/결과 + 워터마크 + 얼굴 자동 감지 + 저장, 반응형·터치·접근성·성능·오류 처리를 마쳤고 **사이드바에 「이미지 모자이크」를 노출했다**(`lib/toolbox/menu.ts`, 배경 편집 다음).
- **다음 시작점(새 세션)**: P6 사용자 확인 → **푸시(요청 시) → 개발망(design6) 배포·확인**(§5 체크리스트, 얼굴 감지는 실제 PC에서 처리 시간 확인) → 완료 처리, 허브 로드맵 다음 메뉴(QR 코드 생성)로.
- 운영망 반영: TOOLBOX 전체 메뉴 완료 후 한꺼번에(허브 §6). 사이드바 메뉴는 P6에서 등록했다.
- 테스트 시 주의: 사용자가 로컬 dev 서버(3000)를 띄워 둔 경우가 많다. 두 번째 `next dev`·`next build`를 돌리면 `.next`가 덮어써져 사용자 서버가 404가 난다 → 3000이 떠 있으면 그 서버로 E2E를 돌린다.

### 1-2. 미결 항목 — ✅ 모두 확정 (2026-10-07)

- **Q8. 「모양」의 의미** → **영역(선택 범위)의 모양**: 사각형 / 타원·원. (선택지가 사각형·타원/원이라 이렇게 적용하고 사용자가 제안대로 확정)
- **Q9. 「영역 작업」 선택지** → ~~「영역 편집 · 이동」/「새 영역 그리기」 드롭다운~~ → **2026-10-07 개편: 탭처럼 보이는 버튼 두 개 「이미지 전체」/「영역 지정」**(§2, 「P2 후속」). 「전체 영역」 버튼은 없앴다.
- **Q10. 「랜덤 픽셀」** → **제외**(사용자 결정: 거친 픽셀과 별 차이가 없으면 넣지 않는다)
  - 판단 근거: 참고 화면에 동작 정의가 없어 제안안은 새로 만든 것이었다. 같은 셀 크기에서 가리는 정도는 거친 픽셀과 같고 **질감(잡음)만 다르다.** 모자이크의 목적(가리기)에 기능 차이가 없으면서 무작위 seed·셀 해시·테스트가 늘어난다. 패턴 한 종류 = 함수 하나라 필요해지면 나중에 추가하기 쉽다(Q11).
- **Q11. 후속 패턴** → 육각형·삼각형·원형(점)·픽셀아트·랜덤 픽셀은 **MVP(P0~P6) 완료 후 필요하면 패턴 선택지에 추가**한다. 지금은 구현하지 않는다.

**이전 미결 항목 처리 결과** (2026-10-07 개정): 참고 화면 있음(Q1) · 영역 도구 = 사각형·타원/원, 브러시 제외(Q2) · 효과는 **영역별**(Q3-B) · 강도 1~100(Q4 개정) · 영역 가장자리는 셀 격자를 그대로 둔 채 영역으로 자른다(Q5) · 얼굴 자동 감지 **포함**(Q6 번복) · 효과별 옵션은 §2.

## 2. 기능 명세 (참고 패널 기준)

**화면 구성**: 이미지 편집·분할·배경 편집과 같은 틀 — 좌측 작업 영역(툴바 + 미리보기) + 우측 410px 속성 패널(xl 이상), xl 미만은 「편집 옵션」 Sheet
- 불러오기: 클릭·드롭·붙여넣기(공용 `ImageUploadZone`), `load.ts`(EXIF 보정·20MB·픽셀 상한). GIF는 첫 프레임.
- 미리보기: 이미지를 화면에 맞춰 표시한다. 확대/축소(휠·핀치·캔버스 오른쪽 아래 공용 `ZoomControls`)·화면 이동. 영역은 이미지 위에 윤곽선(선택 시 크기 조절 핸들)으로 표시한다.

**캔버스 위 툴바**(이미지 편집과 같은 위치·스타일, 한 줄. 좁으면 가로 스크롤 + 양끝 페이드) — 왼쪽부터
1. **되돌리기 · 다시 실행**
2. **모양**: 사각형(□) · 타원/원(○) — 아이콘 토글. 이미지 전체에서는 비활성
3. **패턴**: 거친 픽셀(격자 아이콘) · 부드러운 블러(물방울 아이콘, P3 전까지 비활성·툴팁 「준비 중」)
4. **보기**: 원본 | 비교 | 결과 + 영역 윤곽 표시(눈 아이콘)
5. **선택 영역 삭제 · 영역 모두 지우기**
6. (오른쪽 끝) **새 이미지 열기 · 단축키(?)**
- 모양·패턴 아이콘은 **지금 바꾸는 대상**의 값을 보여 주고 바꾼다: 이미지 전체 → 전체 영역, 영역 지정에서 영역을 선택했으면 그 영역, 선택이 없으면 새 영역 기본값.
- 아이콘마다 툴팁(이름·단축키). 마우스로 누른 버튼은 포커스를 풀어 이어지는 Space·단축키가 버튼에 가지 않게 한다.
- **얼굴 자동 감지**(P5): 패턴 오른쪽에 스캔 아이콘 버튼을 둔다(감지 중에는 아이콘이 돈다). 설정·진행·취소는 패널의 「얼굴 자동 감지」 섹션.

**우측 속성 패널 구성(위에서 아래로) — 최소화(사용자 결정 2026-10-07)**

1. **모자이크 편집**
   - **영역 작업**(탭 모양 버튼 2개, `role=radiogroup` — 항목이 한눈에 보인다): **「이미지 전체」 / 「영역 지정」**(기본)
     - **영역 지정**: 이미지의 **빈 곳을 끌면 새 영역**을 그린다(현재 「모양」). 영역 클릭 = 선택, 끌기 = 이동, 핸들 = 크기 조절, 빈 곳 클릭 = 선택 해제. **화면 이동은 Space를 누른 채 끌기·두 손가락·휠·줌 컨트롤**이다. 기존 영역 안에서 끌면 이동이라, 그 위에 겹쳐 새 영역을 그리려면 영역 바깥에서 시작한다.
     - **이미지 전체**: 이미지 전체에 모자이크를 적용한다(패턴·강도만 조절). 영역 윤곽·세부 위치/크기·모양·영역 삭제는 숨기거나 비활성이고, 끌면 화면 이동이다.
     - **이미지 전체를 누르면 지정해 둔 영역은 지워진다**(사용자 결정). 지워질 영역이 있으면 토스트(「지정한 영역 N개를 지우고…」 + **되돌리기** 버튼)로 알리고, 되돌리기(버튼·Ctrl+Z)로 복구된다. 반대로 「영역 지정」으로 돌아오면 전체 영역은 지워지고 영역 0개에서 시작하며, **전체에서 조절한 패턴·강도는 새 영역 기본값으로 이어받는다**.
     - 같은 항목을 다시 누르면 「결과」 보기·윤곽 표시로 돌아온다(원본·비교 보기나 윤곽을 숨긴 상태에서 편집으로 복귀).
   - **모자이크 강도**: 슬라이더 1~100(기본 22). 아래에 「새 영역 · 강도 22」·「선택 영역 · 강도 22 · 셀 약 18px」·「이미지 전체 · 강도 22 · 셀 약 18px」처럼 상태와 환산값을 보여 준다.
   - **세부 위치·크기**(접이식, **기본 접힘**): 위치 X / 위치 Y / 영역 너비 / 영역 높이(원본 이미지 px, 정수 입력). 접힌 상태에서는 선택 영역의 요약(「X 80 · Y 90 · 180×140」)을 보여 준다. 이미지 전체에서는 숨긴다.
   - 짧은 안내 문구 1~2줄(모양·패턴은 툴바에서 고른다, 단축키는 툴바 키보드 아이콘(?)). 긴 단축키 설명은 도움말 대화상자로 옮겼다.
   - (아래 별도 섹션) **얼굴 자동 감지**(P5)
2. **얼굴 자동 감지**(P5): 「얼굴 자동 감지」 버튼(감지 중에는 「감지 중… N% · 취소」, 모델 준비 중에는 「모델 준비 중… · 취소」) · ☐ 「불러올 때 얼굴 자동 적용」 · 「얼굴 여백 · %」(0~100, 기본 30) · 안내 「자동 감지는 얼굴을 놓치거나 얼굴이 아닌 곳을 잡을 수 있어요. 결과를 직접 확인하고 필요한 영역을 추가·삭제하세요…」(얼굴에는 「타원/원」이 어울린다는 안내 포함). 찾은 얼굴마다 영역을 추가하고 현재 새 영역 기본값(모양·패턴·강도)을 따른다. 이미지는 서버로 전송되지 않는다.
3. **워터마크**(P4) — **이미지 편집의 워터마크 패널을 그대로 공용으로 쓴다**(`WatermarkPanel`): 켜는 스위치(기본 꺼짐, 꺼 두면 안내 한 줄만 차지) → 종류(텍스트 / 로고 이미지) · 텍스트(문구·글꼴·색상·굵게·테두리·크기) 또는 로고(파일 선택·변경·삭제·크기, 20MB 이하 공용 상한) · 불투명도 · 회전 · 배치(위치 지정 9칸 + 여백 / 타일 반복 + 간격). 크기·여백·간격은 이미지 짧은 변 대비 %다. 모자이크 결과 **위에** 합성한다(영역과 겹쳐도 워터마크가 위). 설정은 이미지 편집과 **공유**된다(저장소·기본 문구 `© Penta Security`).
4. **이미지 정보**: 파일명, 이미지 크기, 원본 용량, 영역 수(이미지 전체면 「이미지 전체」)
5. **저장**: 파일명(기본 `원본명_mosaic`, 수정 가능 — 이전 메뉴와 동일) · 저장 형식(PNG 투명 유지 / JPG 투명→흰색 / WebP) · 품질(JPG·WebP) · 「저장」 버튼
   - **영역이 하나도 없고 워터마크도 꺼져 있으면** 저장 버튼 비활성 + 안내(원본과 동일하므로). 영역 없이 워터마크만 켜도 저장할 수 있다.
   - 안내: 「가린 부분은 저장한 파일에서 원본으로 복원할 수 없습니다.」 · 「JPG의 투명 영역은 흰색으로 저장합니다. GIF는 정지 이미지로 처리합니다.」

**단축키 도움말**(툴바 키보드 아이콘 또는 `?` 키 — `MosaicShortcutDialog`): 편집(되돌리기·다시 실행·삭제·선택 해제) / 영역(그리기·Shift 정사각형/정원·방향키 1px·Shift+방향키 10px) / 화면(Space+끌기·휠·도움말). 입력창에서는 동작하지 않고, 도움말이 열려 있는 동안 편집 단축키는 막는다.

| 거친 픽셀 | 정사각 셀로 나눠 **셀 평균색**으로 채운다 | 셀 한 변 = 이미지 짧은 변 × 강도 / 1000, 최소 2px (예: 짧은 변 800px에서 강도 22 → 약 18px) |
| 부드러운 블러 | 가우시안 근사(상자 흐림 3회, 알파 가중). 영역 바깥 색도 섞어 계산해 경계가 자연스럽다 | 반경 = 위와 같은 환산 크기의 절반 |

- 공통: 셀 격자는 **이미지 왼쪽 위(0,0) 기준 고정**이다. 영역을 옮기거나 크기를 바꿔도 셀 위치가 변하지 않고, 이웃한 영역끼리 격자가 이어진다.
- 투명 PNG: 셀 평균은 **알파 가중 평균**(투명한 픽셀이 색을 오염시키지 않게), 알파는 셀 평균 알파.
- 부드러운 블러 반경은 같은 강도 셀 크기의 절반(최소 1px, 실제 번지는 거리는 약 3배), 작업 넓이가 크면 줄인 해상도에서 계산한다(§3).
- 영역 가장자리: 영역 모양(사각형·타원)으로 **픽셀 단위로 자른다**. 경계에서 셀이 잘려도 셀 색은 전체 셀 기준이다(타원은 1px 안티에일리어싱).
- 영역이 겹치면 **나중에 만든 영역이 위**에 그려진다. 각 영역은 **항상 원본에서** 계산하므로 겹쳐도 효과가 누적되지 않는다.
- 최소 영역 크기 8px(이미지가 더 작으면 1px). 영역은 이미지 안으로 제한한다.

**단축키(제안)**: Ctrl/⌘+Z 되돌리기, Ctrl/⌘+Shift+Z·Ctrl+Y 다시 실행, Delete/Backspace 선택 영역 삭제, Esc 선택 해제, 방향키 1px·Shift+방향키 10px 이동. 입력창·Sheet 안에서는 쓰지 않는다. Space를 누른 채 끌기·휠·두 손가락은 어느 모드에서나 화면 이동/확대.

**기타**: 도구·패턴·모양·강도·워터마크 설정은 새 이미지를 열어도 유지하고(영역과 되돌리기 기록은 버림), 영역이 있으면 페이지 이탈 경고(배경 편집 P4-1과 동일).

## 3. 구조 (제안)

**영역 데이터(객체 목록)**
```
Region = { id, shape: 'rect' | 'ellipse', x, y, width, height   // 원본 px, 정수
         , pattern: 'pixel' | 'blur', strength }      // 1~100
```
- 영역 목록은 작아서 **되돌리기를 스냅샷 방식**으로 한다(공용 `history.ts`의 `pushHistory`). 이동·크기 조절은 **놓을 때 한 번** 기록한다. 배경 편집 같은 작업 기록 재실행이 필요 없다.
- 입력 이미지 `original`(불변)과 영역 목록만 상태이고, 결과는 매번 합성한다.

**합성(렌더) 규칙**
1. 결과 캔버스 = `original` 복사
2. 영역을 생성 순서대로, 각각: ① 영역의 외접 사각형(+블러 반경 여백)만 `original`에서 효과 계산 → ② 영역 모양(사각형/타원)으로 잘라 결과 위에 얹기
- 불변식(테스트 기준): **영역 밖 픽셀은 원본과 바이트까지 같고, 영역 안은 효과 결과와 같다.** 영역을 비우면 원본과 같다.
- 효과를 이미지 전체 크기로 만들지 않고 **영역 크기만큼만** 계산하므로 메모리 부담이 작다.

**성능 정책(✅ P0 측정으로 확정, 측정값은 §4 P0)**
- **거친 픽셀: 메인 스레드, 실시간 반영.** 4096²에서 영역 전체도 약 0.15초, 25%는 0.04초, 얼굴 크기는 5~10ms다. 슬라이더를 끄는 동안 반영하고, 영역 이동·크기 조절 중에도 프레임당 한 번(rAF) 다시 계산한다. Worker는 쓰지 않는다.
- **부드러운 블러: 작업 넓이가 크면 줄인 해상도로 계산한다**(✅ P3에서 구현·측정 확정). 정밀 상자 흐림은 비용이 작업 넓이에 비례해 4096² 전체 3.3초·25%(반경 205) 1.5초로 기준(1초)을 넘는다. 영역+번지는 거리(반경 × 3)를 읽어 흐리되, 작업 넓이가 **40만 px를 넘으면 2의 거듭제곱(최대 1/8)으로 줄여** 흐린 뒤 영역만 다시 키운다. **배율은 반경을 넘지 않는다**(줄인 뒤 반경 ≥ 1px). 작은 영역은 배율 1(원본 해상도)이라 정밀 계산이다.
  - 처음 계획한 「반경 구간별 배율」(8 미만 1 / 16 미만 1/2 …)은 쓰지 않았다. 측정해 보니 **오차는 배율·반경과 거의 무관**(평균 0.4~1.1 / 255)하고 비용은 **작업 넓이**에 비례하므로, 넓이 기준이 같은 정밀도에서 더 빠르다(§4 P3 측정표).
  - 계산은 메인 스레드이고 Worker는 쓰지 않는다(최악의 경우도 4096² 전체 약 0.7초).
  - 상자 흐림은 가로를 행마다 네 채널 누적합 한 번에, **세로는 행 단위 열 누적합**으로 계산해 열 방향 접근을 없앴다(2048²에서 약 2배 빠름).
  - 블러 영역을 끌어 옮길 때도 매 프레임 다시 계산한다(얼굴 크기 25ms/단계). 큰 영역(2048² 이상)은 약 60ms/단계라 P6에서 최적화를 검토한다.
- 거친 픽셀의 셀 평균은 영역을 **셀 경계에 맞춘 범위**(영역 + 잘린 셀 전체)에서 구한다(셀 색이 전체 셀 기준이 되도록).
- Safari는 `ctx.filter`(캔버스 블러)를 신뢰할 수 없으므로 **블러는 직접 구현**한다(상자 흐림 3회, RGBA 알파 가중). 배경 편집 `refine.ts`의 `boxBlur`는 Float32 단채널이라 RGBA용(Uint8 premultiplied)으로 새로 만든다.

**순수 로직 `lib/toolbox/mosaic/`**
- `types.ts`: `Region`·`Pattern`·`Shape`, 기본값, 범위, `cellSizeFor(strength, width, height)`(강도 → 셀 px)

  - **좌표 입력**: Enter·포커스 이동 때 반영. 위치(X·Y)는 크기를 유지한 채 이미지 안에서만, 크기(너비·높이)는 위치를 유지한 채 이미지 가장자리까지·최소 8px. 입력창은 선택이 없으면 비활성.
  - **강도·패턴·모양**: 선택 영역이 있으면 그 영역만, 없으면 **새 영역 기본값**을 바꾼다(「선택 영역 · 강도 N · 셀 약 Npx」 / 「새 영역 · 강도 N」). 「부드러운 블러」·「타원/원」은 「(준비 중)」으로 비활성이다(P2·P3).
  - **전체 영역**: 이미지 전체 크기 영역을 추가하고 선택한다.
  - **저장**: 영역이 없으면 비활성 + 안내. 파일명 기본값 `원본명_mosaic`, 형식 PNG(투명 유지)/JPG(투명→흰색)/WebP + 품질. 윤곽은 저장되지 않는다.
  - 새 이미지를 열면 영역·선택은 버리고 **새 영역 기본값·저장 형식은 유지**한다. 영역이 있으면 페이지 이탈 경고.
  - (P1 당시) 되돌리기/다시 실행·단축키는 P2에서 추가했다.

- **모양 「타원/원」**
  - 영역은 외접 사각형(x, y, 너비, 높이)으로 저장하고 모양만 `ellipse`로 둔다. 합성은 `compose.ts`가 효과 조각을 **타원으로 잘라**(캔버스 `clip`) 얹는다. 타원 안쪽은 효과, 바깥(외접 사각형 모서리 포함)은 원본이다.
  - 캔버스: 타원 윤곽, 선택 시 핸들이 놓이는 외접 사각형을 점선으로 표시. **클릭 판정도 타원 모양**이라 외접 사각형 모서리(타원 밖)를 누르면 선택되지 않는다.
  - **Shift를 누르고 끌면 정사각형·정원**(`squareFromDrag` — 긴 쪽 변에 맞추고 이미지 경계를 넘지 않게 제한). 그리는 중 미리보기도 현재 모양(사각형/타원)으로 보인다. 크기 조절 핸들의 Shift 비율 고정은 넣지 않았다.
  - 패널 「모양」: 선택 영역이 있으면 그 영역의 모양을, 없으면 새 영역 기본값을 바꾼다(되돌리기 가능).
- **보기 방식 「원본 | 비교 | 결과」 + 영역 윤곽 표시**(`MosaicViewBar.tsx`, 미리보기 왼쪽 위 — 배경 편집과 같은 배치)
  - 「원본」: 원본만 / 「결과」(기본): 모자이크 결과 + 영역 윤곽 / 「비교」: 왼쪽 원본·오른쪽 결과, 가운데 경계선(DOM 오버레이)
  - 비교 경계선: 끌기(마우스·터치)와 **키보드**(←→ 1%, Shift 10%, Home/End, `role=slider`)로 조절하고, 새 이미지에서 50%로 돌아간다. Konva는 `clipWidth`가 0이면 클립을 끄므로 0%에서는 원본 그룹을 그리지 않는다(E2E에서 발견).
  - **윤곽·핸들·영역 편집은 「결과」 보기에서만** 쓴다. 원본·비교에서는 화면 이동만 하고, 영역 도구(새 영역 그리기)·전체 영역·영역 생성은 「결과」 보기로 되돌린다. 저장은 보기와 무관하게 항상 모자이크 결과다.
  - **윤곽 표시 토글**(눈 아이콘): 끄면 윤곽·핸들이 사라지고 영역 선택도 막힌다. 저장 결과는 동일하다. 도구를 고르거나 영역을 만들면 다시 켠다.

- `lib/toolbox/mosaic/compose.ts`: `renderBlurEffect` — 영역 + 반경 × 3 여백만 원본에서 읽어 흐린 뒤 영역 크기로 잘라 돌려준다(영역 바깥 색이 섞여 경계가 자연스럽다). 배율 1이면 `getImageData` → `boxBlurRGBA` → 자르기, 배율 > 1이면 캔버스로 줄여(`imageSmoothingQuality: high`) 흐린 뒤 영역만 원래 크기로 되돌린다. 거친 픽셀은 `renderPixelEffect`로 분리했다. 타원은 기존대로 효과 조각을 타원으로 잘라 얹는다.
- UI: 툴바 「부드러운 블러」 아이콘 활성(툴팁에서 「준비 중」 제거), 패널 강도 설명이 패턴에 따라 「셀 약 Npx」 / 「반경 약 Npx」로 바뀐다. 이미지 전체에서도 패턴을 바꿀 수 있다.

- **모델 파일 위치: 자체 호스팅**(`public/tool-models/yunet/`, 같은 출처). 배경 편집 모델(90MB)과 달리 0.23MB라 저장소에 넣는 부담이 작고, 외부 CDN(Hugging Face) 의존·CORS·가용성 문제가 없다. MIT 조건에 따라 `LICENSE`와 출처·커밋(`3cc26e7f…`)·SHA-256을 `README.md`로 함께 두었다. 앱은 내려받은 뒤 **SHA-256을 확인**한다(`8f2383e4…2fa4`). wasm은 배경 편집과 같이 jsDelivr에서 받는다.
