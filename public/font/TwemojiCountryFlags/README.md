# Twemoji Country Flags (국기 이모지 폴리필 글꼴)

- 용도: Windows의 Chrome·Edge처럼 국기 이모지를 그리지 못하는 환경에서만 TOOLBOX「특수 문자 및 이모티콘」이 불러오는 웹폰트(감지는 `lib/toolbox/special-characters/emoji-support.ts`).
- 출처: npm `country-flag-emoji-polyfill@0.1.10`(TalkJS)의 `dist/TwemojiCountryFlags.woff2` — Twemoji Mozilla 글꼴에서 국기 글리프만 추출한 subset(78KB).
- 라이선스: 코드 MIT, **국기 그림은 Twemoji(Twitter, Inc. 및 기여자) CC BY 4.0** — 자세한 내용은 같은 폴더의 `LICENSE.md`. 앱 화면에 출처를 표기한다.
